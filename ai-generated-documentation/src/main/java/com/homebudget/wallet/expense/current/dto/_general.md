## General Documentation for dto package 

This package provides Data Transfer Objects (DTOs) for representing various data entities within a home budget application.  DTOs are lightweight objects designed to encapsulate specific data sets, facilitating efficient communication between different components of the application. The `ExpenseDTO` class, for instance, represents an expense record with details like value, user associated with it, wallet ID, and a description. These DTOs ensure data consistency and clarity during transmission between modules, promoting modularity and maintainability within the application.
